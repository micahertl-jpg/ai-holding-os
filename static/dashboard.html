Live Trading — REAL MONEY, real brokerage orders

Real Trade History

Reuses the SAME strategy (watchlist, position/trade/exposure limits) as paper trading above — only execution differs. Every trade also passes a second, independent absolute-dollar safety layer (per-trade cap, daily-loss circuit breaker) before it ever reaches the broker; see tasks/live_trading_safety.py. Requires ALPACA_API_KEY/ALPACA_API_SECRET/ALPACA_BASE_URL to be configured — without an explicit live ALPACA_BASE_URL, orders can only ever reach Alpaca's own paper simulator, never real money. Set LIVE_TRADING_KILL_SWITCH=1 to halt all live trading instantly, no deploy required.

Strategy Backtesting — tests against real historical data, no real or paper money moves

Reuses the exact same decision/risk-limit logic as paper trading, run against real historical daily prices instead of live quotes. Every candidate is scored on a held-out VALIDATION window it was never tuned against — the defense against a strategy that looks great on the data it was shaped by and nowhere else; a candidate's real bar is never win rate alone, but net P&L, profit factor, sample size, and max drawdown together. Bounded to at most max_candidates tries — "none of these were good enough yet" is a normal, expected result, not a bug. Nothing here is ever auto-activated; promote a candidate yourself via the strategy override, below. Requires ALPHAVANTAGE_API_KEY; each simulated day is one real LLM call, so cost scales with (days) × (candidates tried).
